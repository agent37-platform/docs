---

Hermes Desktop drives your instance over SSH. Set up [SSH access](/agents-api/ssh) once:

```bash
npm install -g agent37
export AGENT37_API_KEY=sk_live_...   # https://www.agent37.com/dashboard/cloud/api-keys
agent37 ssh setup
```

Then in **Settings**, **Gateway**, pick **Connect via SSH**:

| Field | Value |
| --- | --- |
| Host | `<instance-id>.agent37.app` |
| User | `node` |
| Everything else | Leave blank |

Click **Test SSH**, then **Save and reconnect**. Done.

<Frame caption="Hermes Desktop, Settings, Gateway.">
  ![Hermes Desktop's Gateway settings with the Connect via SSH mode selected](/images/hermes-desktop-ssh-gateway.jpg)
</Frame>

If **Test SSH** fails, the instance is stopped, on an old image, or not running Hermes: [start](/agents-api/instances/start) or [update](/agents-api/instances/update) it and retry.
