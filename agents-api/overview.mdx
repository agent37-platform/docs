Use the **Hosting API** to manage sandboxes. Agent templates also provide an **Agent API** for conversations and tools inside an instance.

Start with [Create an instance](/agents-api/instances/create) for a request you can copy, or follow the [Quickstart](/quickstart) to create a sandbox, run a command, and reach a service.

Request examples include required and optional fields in curl, Python, and Node. Replace the example values with yours and omit optional fields you do not need; the field reference describes defaults, accepted values, and alternative forms.
