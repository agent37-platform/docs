An instance is a persistent, isolated computer for code, services, or agent harnesses. Choose a template, run commands, and reach services on its ports.

<CardGroup cols={2}>
  <Card title="Create an instance" icon="plus" href="/agents-api/instances/create">Start with a copyable request.</Card>
  <Card title="Run commands" icon="code" href="/agents-api/exec">Execute code on your sandbox.</Card>
</CardGroup>

## Endpoints

| Method | Path | Returns |
| --- | --- | --- |
| `POST` | [`/v1/instances`](/agents-api/instances/create) | `201` with the full instance object |
| `GET` | [`/v1/instances`](/agents-api/instances/list) | `200` `{ "data": [...] }`, newest first, each the full instance object |
| `GET` | [`/v1/instances/{id}`](/agents-api/instances/get) | `200` with the full instance object |
| `PATCH` | [`/v1/instances/{id}`](/agents-api/instances/edit) | `200` with the full instance object |
| `DELETE` | [`/v1/instances/{id}`](/agents-api/instances/delete) | `200` `{ "id": "...", "deleted": true }` |
| `POST` | [`/v1/instances/{id}/stop`](/agents-api/instances/stop) | `200` `{ id, status }` ack |
| `POST` | [`/v1/instances/{id}/start`](/agents-api/instances/start) | `200` `{ id, status }` ack |
| `POST` | [`/v1/instances/{id}/restart`](/agents-api/instances/restart) | `200` `{ id, status }` ack |
| `POST` | [`/v1/instances/{id}/update`](/agents-api/instances/update) | `200` `{ id, status, image_ref, image_digest, template_revision }` ack |
| `POST` | [`/v1/instances/{id}/resize`](/agents-api/instances/resize) | `200` `{ id, status, resources }` ack |
| `POST` | [`/v1/instances/{id}/fork`](/agents-api/instances/fork) | `201` with the new instance's full object |
| `GET` | [`/v1/instances/{id}/backups`](/agents-api/instances/list-backups) | `200` `{ "data": [...] }`, newest first, each a [backup record](/agents-api/instances/list-backups) |
| `POST` | [`/v1/instances/{id}/backups`](/agents-api/instances/create-backup) | `201` with the backup record |
| `POST` | [`/v1/instances/{id}/restore`](/agents-api/instances/restore) | `200` `{ id, status }` ack |
