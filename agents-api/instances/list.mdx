<RequestExample>
```bash curl
curl -X GET https://api.agent37.com/v1/instances \
  -H "Authorization: Bearer sk_live_..."
```

```python Python
import requests

response = requests.get(
    "https://api.agent37.com/v1/instances",
    headers={"Authorization": "Bearer sk_live_..."},
)
response.raise_for_status()
print(response.json())
```

```javascript Node
const response = await fetch("https://api.agent37.com/v1/instances", {
  method: "GET",
  headers: {
    Authorization: "Bearer sk_live_...",
  },
});
if (!response.ok) throw new Error(await response.text());
console.log(await response.json());
```
</RequestExample>

<ResponseExample>
```json 200 (excerpt)
{
  "data": [
    {
      "id": "ab12cd34ef",
      "status": "running",
      "url": "https://ab12cd34ef.agent37.app"
    }
  ]
}
```
</ResponseExample>

Authenticate with `Authorization: Bearer sk_live_...` on `https://api.agent37.com`.

## Response

`200` with `{ "data": [...] }`. Each item is the full [instance object](/agents-api/instances/object); the example shows selected fields.
