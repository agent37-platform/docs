# Homepage artwork

Conceptual illustrations for the Agent37 Cloud documentation homepage. The cards share a muted palette and concrete subjects. Most assets are editable SVGs; Quickstart uses an optimized WebP illustration.

| Asset | Subject |
| --- | --- |
| `quickstart.webp` | An agent working with a terminal and files inside a sandbox, with a shield representing isolation. Generated with imagegen and exported at 1440 × 960. |
| `templates.svg` | Hermes, OpenClaw, and Claude Code with their official brand marks, alongside a slot for your own image. This is an illustrative subset, not the complete catalog. |
| `api-reference.svg` | `POST /v1/instances` and a fragment of its `201 Created` response. |
| `agent-docs.svg` | The documentation index passed to a coding agent. |
| `coding-agent.svg` | A coding agent with persistent working files. |
| `live-preview.svg` | A service reached through a preview URL. |
| `browser.svg` | Browser automation with a live desktop. |

These are conceptual illustrations, not screenshots of product interfaces. Card text carries the same information without relying on the images. Keep API snippets aligned with their reference pages and keep labels legible at card size.

The template illustration embeds these official assets, with no external image requests:

- [Hermes app icon](https://github.com/NousResearch/hermes-agent/blob/main/assets/icon-master.svg), from Nous Research.
- [OpenClaw mark](https://openclaw.ai/favicon.svg), from the OpenClaw website.
- [Claude mark](https://mintcdn.com/claude-code/c5r9_6tjPMzFdDDT/logo/light.svg), extracted from the Claude Code documentation wordmark.
