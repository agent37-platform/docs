Use these docs with the coding agent you already work with. Start with the [documentation index](https://www.agent37.com/docs/llms.txt), then let your agent fetch the pages it needs.

## Give your agent a starting task

Copy this prompt into your coding agent:

```text
Read https://www.agent37.com/docs/llms.txt and the quickstart linked there.
Use the relevant API reference pages to build a script that creates an
Agent37 sandbox, runs a shell command, and reaches a service over HTTPS.
Read the API key from a server-side environment variable.
Include a cleanup command to delete the instance when I am finished.
```

Replace the task with what you want to build, such as hosting a harness or running your own Docker image.

If the agent has no API key, point it at [Sign up](/agents-api/signup): one unauthenticated `POST /v1/signup` returns a workspace, a key, and a payment link, so it can onboard itself and then [fund the wallet](/agents-api/billing#fund-the-wallet-from-the-api) without a person in the loop.

## Choose the runtime for your task

| Your workload | Tell your coding agent |
| --- | --- |
| Full Linux VM, Docker-in-Docker, or Compose | Read [VM instances](/agents-api/vm-instances). Create with `"template": "agent37-ubuntu"` and `"type": "vm"`; Docker is already running. |
| Android phone automation | Read [Host an Android phone](/agents-api/android). Create with `"template": "agent37-android"` and `"type": "vm"`; wait with `android-wait`, then use ADB and `android-shot` through exec. |
| Linux desktop automation | Read [Browser and desktop](/agents-api/desktop). Ubuntu VMs include an XFCE desktop; bring your own screenshot, click, and recording tools. |

VMs require a funded workspace. The Android template includes Android 14, ADB, and a browser screen on port `6901`. The guides include the exact requests and current limits.

## Choose the documentation format

| Resource | Use it for |
| --- | --- |
| [Documentation index](https://www.agent37.com/docs/llms.txt) | Find the relevant pages without loading the entire reference. |
| [Complete documentation](https://www.agent37.com/docs/llms-full.txt) | Read the guides and reference in one text file when your agent has room for the full context. |
| **Copy page** on any docs page | Give your agent the specific page you are reading. |
| [MCP server](https://www.agent37.com/docs/mcp) | Let your agent search these docs as a tool: `claude mcp add --transport http agent37-docs https://www.agent37.com/docs/mcp`. |
| [Agent skill](https://www.agent37.com/docs/skill.md) | Install it with `npx skills add https://www.agent37.com/docs` so your agent loads Agent37 knowledge when the task needs it. |
| [CLI](https://www.npmjs.com/package/agent37) | Build templates and SSH into instances from your terminal with `npx agent37`. |

For endpoint examples, start with the [REST API reference](/agents-api/overview). For the sandbox walkthrough, use the [Quickstart](/quickstart).
